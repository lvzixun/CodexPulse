# 0.1.26 界面优化与 macOS 久置重开

保留 Rust / Tauri / Svelte 实现和现有四页布局。本次修复 macOS 隐藏五分钟后销毁 WebView、再次打开需要重新绘制导致的空白闪烁：macOS 保留已绘制窗口，隐藏期间暂停前端时钟与快照读取，重开补读最新状态；Windows 继续沿用隐藏五分钟释放窗口的策略。该取舍会保留 macOS 后台 WebView 内存，不宣称资源占用下降。

模型按名称稳定分配八组深浅色板，排序和翻页不改变颜色；进度条、展开标题、用量、速度曲线 / 填充 / 数据点 / 模式标签和详情链接使用同一模型颜色。模型与 Session 展开加入 180 ms 动效，尊重系统减少动态效果。速度采样读数放在图表下方，仅展示本地时间、tok/s 和模式，删除遮挡曲线的大浮层与重复 SVG 原生提示。按采样时间保持选中点高亮，后台刷新后读数使用最新加权汇总，避免对象代理比较和重复时间样本导致选中显示不一致。

Session 一次展开只显示项目 / 模型、三项主要指标与一行输入 / 缓存 / 输出；去掉长 ID、重复解释、模型 / 计价分页与嵌套展开。计价不完整时保留短提示，未知字段仍显示未知。后台刷新保留列表、详情和滚动位置。

macOS 使用系统 Popover 材质、系统字体与 WebKit 原生开关的固有尺寸，调整深浅色文字 / 卡片 / 边框对比度。Windows 使用 40 × 20 开关；Win10 继续强制关闭玻璃，Win11 保留 Acrylic。设置刷新组只在相邻组之间显示一条分隔线。应用图标替换为蓝色渐变 Pulse 标记，界面 SVG 和平台图标由同一几何生成；菜单栏继续使用系统单色符号。
