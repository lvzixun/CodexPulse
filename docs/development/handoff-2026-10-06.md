## 已实现的主要链路

- Rust / Tauri 2 / Svelte 5 / TypeScript / SQLite，单产品窗口、托盘、浮窗、主题及材质回退。
- Windows 与已运行 WSL 本地日志增量采集、镜像 / 归档去重、累计差分、标题同步，事务提交 facts 与断点。当前 schema 5，已有标题表和模型范围覆盖索引。
- 固定点参考计价、30 个自然日汇总、session / 模型双向分页、模型下钻、名称隐藏、额外来源及手动 WSL 配置。
- HTTPS 额度与 Codex Resets 两套刷新调度、持久化、缓存 / 身份隔离、站点中文译文、公开挑战记录及未读状态。
- 系统时区自动检测和分批原子重建；后台更新不覆盖设置草稿。隐藏 WebView 后恢复路由 / 分类选择 / 滚动已验证一轮，尚未做长期压力验收。

本次新增 UI：Sessions 简洁列表与行内详情、全量结果运行优先、模型占比细横条、重置信息前置。通知开发属于曾经的未提交工作，已经撤回；依赖、原生命令、安装通知注册逻辑均回到无通知状态，HTML 演示通知开关也移除。
