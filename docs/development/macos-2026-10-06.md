本轮在 macOS 上接续 [开发交接](handoff-2026-10-06.md)，实现菜单栏宿主、本机来源与 App / DMG 构建。随后按用户反馈修正窗口圆角、材质和菜单栏图标风格。实现已可本机运行；以下明确区分实际观察与仍待验收的项目。

## 平台实现

- `LSUIElement` 与 Accessory 激活策略：首次启动只建立菜单栏图标，不创建 WebView，不显示 Dock 图标。
- 菜单栏使用 AppKit 的 `waveform.path.ecg` SF Symbol，18 pt、regular、template，颜色交给系统适配。不可用时保留 22 pt Retina 模板图标。状态刷新只修改 tooltip，不替换原生图像；旧版本调用 `set_icon` 会丢失模板属性，导致深色菜单栏中的图标变黑。
- 左键切换同一个详情面板，右键保留设置 / 退出原生菜单。单实例启动及 Finder 再次打开可显示详情。Esc / 收起按钮隐藏；窗口失焦及 `NSApplicationDidResignActiveNotification` 收起面板。观察者在主线程退出时移除，无全局输入监听或输入监控权限。
- 面板为 400 × 680 逻辑点，根据 status item 原生矩形选择屏幕并限制在工作区内；跟随当前 Space，可用于全屏应用。小屏与 Retina / 负坐标定位由几何测试覆盖，真实多屏仍待检查。
- 原生内容层裁切与材质半径统一为 20 pt。macOS 26 优先使用 AppKit Liquid Glass，旧系统回退 Popover 材质；WebView 保持透明，去掉遮盖原生材质的高不透明度灰蓝底色。macOS 专属样式使用系统字体、灰色分段导航和 WebKit 原生 HTML 开关；减少透明度 / 增加对比度或关闭玻璃时回退不透明背景。
- 总览按用户反馈明确分为两个信息区：当前 / 最近会话包含标题、来源 / 模型、项目与三项会话指标；最近 30 天累计独立包含总计、估算、日期图表及模型分类入口。来源 / 模型不再放在会话区标题旁，以免看起来是另一类数据。最新发布版已观察两组清楚分离，点击会话标题仍进入 Sessions。
- 本机默认读取 `CODEX_HOME`，否则 `$HOME/.codex`，支持额外本机绝对路径。macOS 不执行 WSL 探测，不显示 WSL / 桌面浮窗 / 置顶设置。共享配置中已有 `windows_*` 字段作为本机来源字段保留，避免无必要的配置迁移；显示名称和来源 ID 使用 macOS。
- 复用共享统计、分页、标题索引、消息和 HTTPS 额度采集。数据库位于 `~/Library/Application Support/com.codexpulse.desktop/pulse.sqlite`。隐藏 5 分钟释放 WebView，后台采集继续；导航和选择保留在宿主内存。

## 总览账户资料与累计指标

按用户最终要求将姓名 / @用户名、账户累计 Token 数、每日峰值、最长任务用时、最长 / 当前连续天数放进总览最后的用量统计卡片，与本机最近 30 天统计合并在同一卡片内，账户累计位于最后，以分隔线和独立标题区分范围。导航保持总览、模型、Sessions、消息四个入口，不新增统计分页。Token 活动图及对应切换 / 日历计算已删除，远端活动桶也不再传入 IPC 或在前端处理。

已沿用每个来源的 `auth.json` 登录身份，实测固定 `GET https://chatgpt.com/backend-api/wham/profiles/me` 返回 `profile / stats / metadata`，包括三种活动桶。指标含义与 [Codex 官方 App Server 文档](https://learn.chatgpt.com/docs/app-server) 的 `account/usage/read` 一致；直接 HTTPS 路径来自已安装官方客户端并在本机验证，不声称是公开、稳定的 API 合约。只提取所需姓名 / 用户名、五项数值及统计日期，不传递头像 URL、邮箱或原始服务错误。

资料与额度共用自动 / 手动刷新组，分别保留成功 / 失败状态；读取凭据后与请求返回后校验身份，两次请求之间换号会丢弃整组旧结果。资料仅缓存在进程内，不写产品数据库；重启后自动模式重新读取，手动模式等待刷新。现有额度缓存仍按原机制持久化。换号、认证失效或来源变更清除资料，模拟隔离和持久化检查已通过。

本机 `ureq` 默认 WebPKI 返回 `UnsupportedCertVersion`，系统 curl 同一固定 HTTPS 请求成功。macOS 现改用 Rustls 的平台证书校验器，保留证书 / 域名验证与超时、禁止认证重定向；Windows 校验配置不变。手动刷新允许立即重试网络 / 正文读取错误，但保留服务端限流与认证错误的退避，测试覆盖单飞和 429 等待时间。真实 Rust 采集器的额度与资料读取均已成功，最终发布 App 总览已观察到真实姓名 / 用户名与五项指标，导航仅保留原有四项，无 Token 活动图；同页 30 天金额及计价覆盖率已由 AX 状态确认，无 curl / CLI / app-server 产品回退。
