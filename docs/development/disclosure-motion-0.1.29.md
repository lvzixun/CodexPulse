# 0.1.29 模型与 Session 展开动画

两页原来使用 180ms Svelte `slide`，开始时一次性记录加载占位的高度。异步数据让内容变高后，动画仍结束于旧高度，移除动画样式时恢复自然高度。本机受控复现中，模型详情约从 263px 跳至 366px，Session 约从 59px 跳至 137px。Session 首次详情读取还会调用整页滚动恢复；浏览器自动滚动锚定又会改动返回页面时的保存位置。

Windows 与 macOS 共用 `Disclosure` 和高度控制器。用 ResizeObserver 观察内容的自然高度，以原生 Web Animations API 进行 180ms ease-in-out 高度过渡；内容变更或用户反向点击时，从当前渲染高度重新过渡。结束后固定到已测得的自然高度，避免释放固定动画高度时跳变。关闭中的内容禁止交互；收起完成或组件卸载时取消动画并断开观察器。系统减少动态效果开启时立即应用最终高度，运行中的动画也可中断。

不增加网络请求、依赖、后台轮询或 JavaScript 常驻逐帧循环。只有打开 / 关闭中的详情保留观察器；稳定内容不重复启动动画。数据查询、失败缓存及速度统计保持原有行为。

点击展开不执行整页滚动恢复。分页或返回页面时，保留选中项，等待列表、详情与高度动画完成后再恢复滚动位置；用户主动切换条目则取消待恢复位置。仅模型 / Session 内容容器关闭浏览器滚动锚定，避免和应用自己的位置管理冲突；总览、Tibo 和设置保留浏览器默认行为。

## 验证

验证脚本：`scripts/verify-disclosure.cjs`，真实 Svelte + 官方 Tauri IPC mocks，使用合成数据。

- 两平台布局、中英文、320 / 380px，模拟 0 / 120 / 240 / 600ms 返回延迟，检查动画终点与目标高度一致、最终显示完整内容，点击展开没有整页 scrollTop 写入。
- 检查错误 / 空数据、后台更新、快速展开 / 收起与不同条目切换、减少动态效果切换、加载时卸载，以及收起 / 离开页面后观察器归零。
- 在可滚动的小高度窗口验证模型 / Session 的选中项和滚动位置返回恢复。
- 既有中英文 UI 行为、模型速度、外观、前端单元测试、Svelte 和生产 UI 构建随本轮复核。

本机最终回归通过：16 组平台 / 语言 / 延迟组合，动画结束高度偏差均小于 1px；错误 / 空数据、快速切换、资源清理与页面返回位置检查通过。既有 UI 行为和四组模型速度回归、60 组外观、22 项前端 / 更新清单测试通过；Svelte 零错误 / 警告、生产 UI 构建及变更文件格式检查通过。

浏览器回归在本机 Edge 执行，macOS 布局通过平台参数复现；本轮没有 Mac 实机视觉或原生帧率验收。此记录用于确认高度跳变消除及资源生命周期，不将浏览器采样写成原生性能基准。
