# 0.1.42 macOS 活跃日志刷新

本机复现：Codex 0.169.0 持续打开并追加当前 JSONL，FSEvents 没有及时报告追加，直接 vnode/kqueue 观察能收到写入。采集游标主要靠一分钟修复扫描推进；新会话模型延迟显示，速度样本超过一分钟后显示横杠。重启 CodexPulse 后仍复现。

macOS 采集器现在使用已有时钟，每秒检查最近最多 128 个本地会话日志的长度、修改时间及文件标识，只有发生变化时才加入原有去重读取队列。保留事件通知及一分钟全量发现；不新增线程，不每秒遍历目录，不读取 WSL 路径。来源移除、禁用或目录改绑后先验证归属再访问文件，删除文件移出检查集合。文件替换即使长度和修改时间一致也能检测。

读取仍使用原有完整行断点、事务及事实去重，模型和速度沿用已有快照与菜单栏发布。未变化文件只检查文件信息；不完整行等待后续追加，不产生新速度或重复用量。空闲时菜单栏仍按现有规则显示横杠；速度仍为日志支持的本轮平均输出速度，包含等待及工具时间。

回归覆盖持续打开的写入端在无通知时更新模型、速度和完成状态，不完整行和账本不重复计数，来源移除 / 文件删除，候选数量上限与扫描顺序，长度 / 时间相同的文件替换。发布范围仅包含本修复，不包含当前工作区尚未提交的 GPUI 与运行时拆分。

发布验证结果待完成后补充。
