# 0.1.9 拖动区域与本机版本修正

2026-10-07，用户截图反馈重置仍换行、两种窗口都不容易拖动、浅色选中标签难以辨认。

## 原因与行为

截图时正在运行 `D:/codes/CodexPulse/target/release/codexpulse.exe`，PE ProductVersion 为 0.1.6、修改时间 10:21:10；正式 Release 虽已发布 0.1.7，本机旧路径没有同步更新。0.1.7 源码中的重置行已为 flex 横排；本轮保留该布局，不能将截图归因于新版样式失效。

小浮窗原来仅左侧约 23 DIP 状态区允许拖动；展开窗口仅图标 / 标题绑定拖动，顶部空白无效。现改为整条小浮窗，包括模型、速度、留白和边缘都可拖动；展开窗口整个标题栏可拖动，置顶 / 设置 / 收起 / 退出按钮保留独立操作。

小浮窗移动 4 DIP 才开始原生拖动，指针捕获覆盖离开小窗口的情况；拖动后可能产生的 click 不展开，下一次独立点击正常展开，有未读时仍进入消息页。键盘点击不受拖动标记阻挡。标题栏阻止文本选择；无轮询、无新增依赖或后台任务。菜单栏平台仍保留既有顶部拖动能力。

选中 tab 改为主题色 16% 的实底混色、35% 的内描边、主题色文字和加粗，深浅主题与五种强调色均适用；macOS 移除会覆盖该样式的旧白色选中规则。系统高对比模式改用 Highlight / HighlightText。布局尺寸不增加。

## 验证与交付

- Svelte 零错误 / 警告，15 项 Node 检查通过。
- 中英文 Tauri IPC 模拟：标题栏空白 / 标题、操作按钮排除、小于阈值抖动、模型 / 速度区域拖动、越出浮窗边缘、拖动后不误展开及下一次点击恢复通过；既有更新 / Tibo / 菜单回归继续通过。
- `scripts/verify-appearance.cjs` 验证 60 种平台 / 语言 / 主题 / 强调色组合，选中项底色、字色、描边与非选中项可区分，重置标签与值同行；浅色截图人工检查通过。
- 原生构建、本机替换及双平台发布待完成；模拟不能替代 OS 拖动手感验收。
