# 实施状态

设计基线：[CodexPulse v1](../design/codexpulse-v1.md)。本文件记录实际落地程度，不替代设计中的首版要求。

## 已落地的基础

- Rust / Tauri 2 / Svelte 5 / SQLite 工程，锁定依赖。
- 累计 token 差分、模型切换、镜像及归档去重、固定点计价逻辑、未拆分与未计价状态。
- SQLite 事务内同时更新 usage facts、日期及 session 模型汇总、文件断点；失败不推进断点。
- 有界 JSONL 增量读取，未变化文件不读取内容，半行等追加，超大记录有限内存跳过并记录问题。
- 最近 30 个自然日的所有模型总量、模型分类及独立 session 数；最近 10 个 session。
- Windows 单个共用窗口的浮窗 / 详情切换，托盘左键详情、右键设置 / 退出，单实例、原生 Acrylic 调用。
- Windows 日志目录监听及 60 秒修复扫描；已运行 WSL 的路径探测与 30 秒轮询。
- 基础设置持久化、源状态与不可用信息。
- Codex app-server 的 `initialize` / `account/read` / `account/rateLimits/read` 只读调用，哈希账户与 workspace 身份、真实窗口长度、快照缓存、单飞和失败退避。额度子进程启动时有 15 秒全程超时，正常退出清理自建进程。

以上“已落地”表示代码具备路径，不等同于完成原生功能或性能验收。当前 WSL 轮询及路径访问还需要负载、发行版停止及权限场景验证。
