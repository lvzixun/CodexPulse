# 实施状态

设计基线：[CodexPulse v1](../design/codexpulse-v1.md)。本文件记录实际落地程度，不替代设计中的首版要求。

## 已落地的基础

- Rust / Tauri 2 / Svelte 5 / SQLite 工程，锁定依赖。
- 累计 token 差分、模型切换、镜像及归档去重、固定点计价逻辑、未拆分与未计价状态。
- SQLite 事务内同时更新 usage facts、日期及 session 模型汇总、文件断点；失败不推进断点。
- 有界 JSONL 增量读取，未变化文件不读取内容，半行等追加，超大记录有限内存跳过并记录问题。
- 最近 30 个自然日的所有模型总量、模型分类及独立 session 数；session 历史双向游标分页（每页 10 条）、模型 / 日期范围下钻与完整 session 详情。详情展示输入 / 缓存 / 输出、模型分类、历史价格版本及来源、计价覆盖；模型和价格分类每页最多 50 条，不发送全部 facts 给前端。元数据会话或缺失计数显示未知，部分计数标记 `*`；旧 session 时间统一为 UTC 纳秒格式，稳定处理同时间分页和时区偏移。
- Windows 单个共用窗口的浮窗 / 详情切换，托盘左键详情、右键设置 / 退出，单实例、原生 Acrylic 调用。
- Windows 日志目录监听及 60 秒修复扫描；已运行 WSL 的路径探测与 30 秒轮询。
- Windows / WSL 的 `session_index.jsonl` 增量采集，按 ID 与最新更新时间同步真实标题及重命名；独立标题表（schema 4）和读取断点事务提交，后续用量不覆盖名称。总览 / 列表 / 详情统一显示，无标题明确标注“未命名会话”，项目目录独立显示。隔离测试覆盖索引先于日志、历史断点兼容、时间偏移 / 乱序 / 镜像冲突、半行追加、重启、清空标题、批次上限和失败回滚。
- 基础设置持久化、源状态与不可用信息。
- Codex app-server 的 `initialize` / `account/read` / `account/rateLimits/read` 只读调用，哈希账户与 workspace 身份、真实窗口长度、快照缓存、单飞和失败退避。额度子进程启动时有 15 秒全程超时，正常退出清理自建进程。
- Codex Resets 公开状态及近期历史接口、ETag、Retry-After、有界响应、no-store 缓存控制，公告 / 计划 / 预测 / 观察分类及原文入口；消息缓存可离线显示。
- 小浮窗显示“忙 / 闲 / ?”，优先显示较长额度窗口，重要新重置提示优先替代 tokens，普通动态为小圆点。消息 / 挑战的未读签名与已读状态持久化，首次建立历史基线，公告及挑战相同原帖去重。消息按钮按 ID 读取站点已发布中文译文，支持原文切换，后台统计更新不清空译文；译文未覆盖的消息明确提示，尚未接入通用机器翻译。
- Windows 开发 / 发布构建统一 GUI 子系统，WSL / Codex 自建子进程隐藏启动。已检查调试 PE 子系统为 2，并在原生启动进程树观察没有终端子进程。
- 总览和消息页显示最近一次重置及下一次已确认计划：有未来公告时间才显示具体日期，未公布、时间待定、已过期待执行和离线缓存分别表达。Tibo 28 天挑战独立采集服务端 HTML，按美西日期计算挑战进度，显示每日产品改进 / 重置记录和原帖；有界解析、独立退避及缓存控制。已在原生界面观察第 2 天、第 1 天改进及最近重置时间。
- 默认蓝色，提供蓝色 / 紫色 / 青绿 / 琥珀 / 玫红五种强调色，深浅主题分别适配并持久化；原生界面已验证蓝色、紫色、浅色及重启恢复。设置草稿不会被后台数据刷新覆盖，可撤销未保存修改。
- 详情沿用保存的 HTML 演示：顶部品牌与操作、来源行、四个分段导航、三列 session 指标、30 天汇总、模型 / session 列表及底部收起。收起浮窗按最新要求改为 184 × 36 DIP 单行小条，只保留活动图标、额度剩余、当前 session tokens 与展开箭头，精确值 / 模型 / 费用悬停查看。首次加载完成后校正尺寸，消除初次窗口多出的标题栏高度；原生观察约 187 × 39 像素（含系统轮廓）、点击展开及收起返回。可见时钟改为每分钟更新，隐藏时停止。设置从顶部进入，颜色设置最后调整。
- 内置 2026-10-06 核查的 GPT-6.1 Sol / GPT-6 Astra / GPT-6 Luna 版本化参考价，区分档位、单次请求长上下文与缓存写入；未知档位 / 缓存写入 / 请求大小不计价。历史重算与完整模型覆盖仍未完成，详见[价格资源说明](../../resources/pricing/README.md)。
- SQLite 按 schema version 运行事务迁移，重新打开不再重复创建并删除旧查询索引；覆盖旧库升级、重复打开和拒绝未来版本的测试。
- 浮窗位置按显示器、逻辑边距与最近边缘保存，展开沿锚点定位，缩放与工作区边界校正；四项几何测试覆盖 DPI、展开收起、显示器移除和小工作区。
- 仅托盘启动可不创建 WebView；隐藏 5 分钟释放并按需重建，路由、模型 / session 选择和滚动位置保留在宿主内存中。系统透明度关闭或高对比度时禁用原生玻璃并使用不透明背景。
- 在原生开发构建中验证：隐藏 5 分钟后 WebView2 子进程全部退出，后台主进程保留；再次启动同一路径通过单实例入口重建详情，恢复设置页、滚动位置和蓝色主题。
- 10k sessions / 100k facts 的可复现 release 查询基准；schema 4 本机 30 天查询 P95 为 63.47 ms，最近 10 个 sessions 为 0.28 ms。该负载不生成标题记录，新增标题查询走空表；标题索引的增量批次及未变化不读取由隔离测试覆盖。详见[查询基准](query-benchmark-2026-10-06.md)。
- Windows x64 NSIS 安装包与内嵌静态资源的 release 应用已构建。当前安装包（会话名称同步版本）SHA256：`B15BBD54FF2B93F18CB0E31D3C417C7B998BA49941074E46A291C3093605968E`，4,189,733 B。原生启动显示真实数据和保存的默认蓝色。

本轮原生验证：Windows GUI 调试构建启动、约 187 × 39 像素的小浮窗及真实工作中标签；完整中文译文、切回原文、后台更新后保留切换状态；真实 session 首屏列表、未知用量、模型拆分和计价覆盖。发布构建已启动并观察内嵌前端的小浮窗、工作状态和真实用量。消息优先级 / 首次基线 / 重启未读去重 / 范围已读与挑战重复原帖由隔离测试覆盖，尚未用真实新重置公告完成原生端到端验证。
