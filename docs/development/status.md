# 实施状态

设计基线：[CodexPulse v1](../design/codexpulse-v1.md)。本文件记录实际落地程度，不替代设计中的首版要求。

## 已落地的基础

- Rust / Tauri 2 / Svelte 5 / SQLite 工程，锁定依赖。
- 累计 token 差分、模型切换、镜像及归档去重、固定点计价逻辑、未拆分与未计价状态。
- SQLite 事务内同时更新 usage facts、日期及 session 模型汇总、文件断点；失败不推进断点。
- 有界 JSONL 增量读取，未变化文件不读取内容，半行等追加，超大记录有限内存跳过并记录问题。
- 最近 30 个自然日的所有模型总量、模型分类及独立 session 数；session 历史双向游标分页（每页 10 条）、模型 / 日期范围下钻与完整 session 详情。详情展示输入 / 缓存 / 输出、模型分类、历史价格版本及来源、计价覆盖；模型和价格分类每页最多 50 条，不发送全部 facts 给前端。元数据会话或缺失计数显示未知，部分计数标记 `*`；旧 session 时间统一为 UTC 纳秒格式，稳定处理同时间分页和时区偏移。
- Windows 单个共用窗口的浮窗 / 详情切换，托盘左键详情、右键设置 / 退出，单实例、原生 Acrylic 调用。
- Windows 日志目录监听及 60 秒修复扫描；已运行 WSL 的路径探测与 30 秒轮询。
- Windows / WSL 的 `session_index.jsonl` 增量采集，按 ID 与最新更新时间同步真实标题及重命名；独立标题表（schema 4）和读取断点事务提交，后续用量不覆盖名称。总览 / 列表 / 详情统一显示，无标题明确标注“未命名会话”，项目目录独立显示。隔离测试覆盖索引先于日志、历史断点兼容、时间偏移 / 乱序 / 镜像冲突、半行追加、重启、清空标题、批次上限和失败回滚。
- 基础设置持久化、源状态与不可用信息。
- 统计时区自动跟随系统，无选择 / 自定义 / 应用入口；启动及每 60 秒检测，变化时自动分批重建日期桶，再次变化替换旧任务，回到已发布时区取消过期任务。规范化账本按 rowid 分批构建临时日期桶，追上新增 facts 后与最新设置原子提交；重建期间显示旧有效统计，退出 / 失败保留旧状态，不重扫 Codex 日志、不修改历史费用及断点。跨午夜更新范围，处理 DST 午夜缺口 / 重复时间及整日跳过；切换后重置 session 游标和模型下钻日期。六项核心测试及两项桌面自动检测 / 启动持久化测试通过，真实账本两时区独立聚合吻合。10 万 facts 存储层重建总耗时 476 ms、批次 P95 0.379 ms，详见[时区验证与基准](timezone-rebuild-benchmark-2026-10-06.md)。
- 额外 Windows 来源和手动 WSL 发行版 / 用户 / Linux home 配置，每类最多 8 个；总开关、单来源启用、配置撤销及深复制草稿。WSL 自动 home 解析缓存，运行列表每 30 秒检查，停止 / 检测失败的手动来源不入队。新目录重建来源，旧监听及队列清理；网络结果需匹配 ID / home / 用户，配置及额度缓存失效事务保存。Windows 路径禁止填入 WSL UNC，以免绕过发行版检查。停用不删除历史账本，列表显示可读来源名称。
- 标题及项目隐藏分别保存，后台 snapshot / session 页 / 详情返回时移除对应字段，前端对已有详情同步遮蔽并移除悬停名称；保留本地元数据和统计。隔离测试检查隐藏组合、内部名称保留及费用 / tokens 不受影响。
- 额度最终改为固定 HTTPS `wham/usage`，每次重载对应 Windows / WSL Codex home 的凭据、配置及 `.env` 代理，证书验证与 15 秒请求超时，禁止认证重定向；失败不调用 CLI、不自动续期、不改写认证文件。文件凭据已支持，keyring / auto / ephemeral、其他登录方式、自定义后端、过期、401、429 和格式变化有明确状态。凭据与代理值不写日志或数据库；身份及工作区仅存哈希。
- 请求前和返回后复核账号，外部变化使旧结果失效；启动额度缓存先经本地身份验证，账号变化清除来源及聚合缓存。Windows 文件通知及每 5 秒本地探测覆盖外部换号；WSL 使用已运行来源的本地文件，不启动额度 CLI。未变化探测不写库或推送 UI。单飞槽、generation、失败退避及 Retry-After 避免重叠和旧任务覆盖。
- 两组独立额度 / Codex Resets 刷新设置已实现：每组一行名称、合并手动 / 自动间隔的下拉框和刷新按钮，下方显示更新时间，异常按需显示；预设及自定义 30–86400 秒、状态及持久化保留。默认分别自动 300 秒；修改立即保存，无需保存外观草稿。手动关闭该组启动和定时网络请求，保留缓存及其时间；本地 sessions 增量采集和点击翻译独立运行。调度与持久化有隔离测试，原生自动模式已观察两来源 `.env` 代理连接及 60 秒 / 300 秒独立间隔。 简化后的发布界面已验证两行控件及主题一致；额度手动 / 消息自动 300 秒在重启后独立保留，测试后恢复两组自动 300 秒。
