# 实施状态

设计基线：[CodexPulse v1](../design/codexpulse-v1.md)。本文件记录实际落地程度，不替代设计中的首版要求。

## 已落地的基础

- Rust / Tauri 2 / Svelte 5 / SQLite 工程，锁定依赖。
- 累计 token 差分、模型切换、镜像及归档去重、固定点计价逻辑、未拆分与未计价状态。
- SQLite 事务内同时更新 usage facts、日期及 session 模型汇总、文件断点；失败不推进断点。
- 有界 JSONL 增量读取，未变化文件不读取内容，半行等追加，超大记录有限内存跳过并记录问题。
- 最近 30 个自然日的所有模型总量、模型分类及独立 session 数；最近 10 个 session。
- Windows 单个共用窗口的浮窗 / 详情切换，托盘左键详情、右键设置 / 退出，单实例、原生 Acrylic 调用。
- Windows 日志目录监听及 60 秒修复扫描；已运行 WSL 的路径探测与 30 秒轮询。
- 基础设置持久化、源状态与不可用信息。
- Codex app-server 的 `initialize` / `account/read` / `account/rateLimits/read` 只读调用，哈希账户与 workspace 身份、真实窗口长度、快照缓存、单飞和失败退避。额度子进程启动时有 15 秒全程超时，正常退出清理自建进程。
- Codex Resets 公开状态及近期历史接口、ETag、Retry-After、有界响应、no-store 缓存控制，公告 / 计划 / 预测 / 观察分类及原文入口；消息缓存可离线显示。
- 默认蓝色，提供蓝色 / 紫色 / 青绿 / 琥珀 / 玫红五种强调色，深浅主题分别适配并持久化；原生界面已验证蓝色、紫色、浅色及重启恢复。设置草稿不会被后台数据刷新覆盖，可撤销未保存修改。
- 按保存的 HTML 演示还原浮窗与详情布局：额度优先浮窗、顶部品牌与操作、来源行、四个分段导航、三列 session 指标、30 天汇总、模型 / session 列表及底部收起。设置从顶部进入，颜色设置最后调整；原生窗口仅保留系统轮廓。已实际观察浮窗、总览、列表和设置页。
- 内置 2026-10-06 核查的 GPT-6.1 Sol / GPT-6 Astra / GPT-6 Luna 版本化参考价，区分档位、单次请求长上下文与缓存写入；未知档位 / 缓存写入 / 请求大小不计价。历史重算与完整模型覆盖仍未完成，详见[价格资源说明](../../resources/pricing/README.md)。
- SQLite 按 schema version 运行事务迁移，重新打开不再重复创建并删除旧查询索引；覆盖旧库升级、重复打开和拒绝未来版本的测试。
- 浮窗位置按显示器、逻辑边距与最近边缘保存，展开沿锚点定位，缩放与工作区边界校正；四项几何测试覆盖 DPI、展开收起、显示器移除和小工作区。
- 仅托盘启动可不创建 WebView；隐藏 5 分钟释放并按需重建，路由、模型 / session 选择和滚动位置保留在宿主内存中。系统透明度关闭或高对比度时禁用原生玻璃并使用不透明背景。
- 在原生开发构建中验证：隐藏 5 分钟后 WebView2 子进程全部退出，后台主进程保留；再次启动同一路径通过单实例入口重建详情，恢复设置页、滚动位置和蓝色主题。
- 10k sessions / 100k facts 的可复现 release 查询基准；覆盖索引后本机 30 天查询 P95 为 60.43 ms，最近 10 个 sessions 为 0.13 ms。详见[查询基准](query-benchmark-2026-10-06.md)。
- Windows x64 NSIS 安装包与内嵌静态资源的 release 应用已构建，原生启动显示真实数据和保存的默认蓝色。安装包 SHA256：`45D3F77DAFBA916293FDDA769FDB892909B8D7920995288894FF9B72F0895F10`。

以上“已落地”表示代码具备路径，不等同于完成原生功能或性能验收。当前 WSL 轮询及路径访问还需要负载、发行版停止及权限场景验证。
