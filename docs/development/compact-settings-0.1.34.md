# 0.1.34 修复级别缺失和浮窗长度

0.1.33 升级补读只查看提交偏移前 256 KiB；两个实际 Astra 会话的 max / xhigh 设置位于更早的位置，导致显示为未知。补读改为从提交偏移分批向前查找：每批最多读取 512 KiB，窗口重叠以覆盖跨边界记录，进度保存到检查点，可在重启后继续。不回退用量偏移，不重复累计 Token。遇到所属线程设置、显式未知、模型边界或文件开头后结束；新的上下文包含级别时立即取消旧补读，不用较早结果覆盖新设置。

同模型运行会话的推理级别去重、排序后合并显示，例如 `max/xhigh`。其他模型不混入；同模型 Fast 状态不同时显示 `Fast±`，未知级别仍保留未知标记。

Windows 浮窗恢复 184 × 36，模型下方显示级别和 Fast，不再为新增字段直接扩展到 300px。移除紧凑按钮末尾的箭头占位，保留整条点击、拖动、速度与消息提示。macOS 菜单栏由系统按文字自动决定宽度，本次移除设置之间的额外分隔和速度单位前的空格，保留完整模型与级别。

## 验证

- 对真实应用检查点进行只读读取，在隔离的内存账本上执行新补读，两个 Astra 分别恢复 `max` 和 `xhigh`，未修改用户日志或真实应用账本。
- 新增超过旧补读范围的回归：分批上限、重启恢复、其他线程隔离、Token 不重复，以及补读期间的新上下文优先。
- Rust 与前端均验证同模型 max/xhigh 合并、稳定排序、其他模型隔离及 Fast 混合状态。
- 中英文实际 Svelte / IPC 回归验证 184px 下两个 Astra 的 max/xhigh、Fast、速度及重置提示完整可见，原有拖动、点击和消息流程继续通过；文档截图恢复原尺寸。
- 本地 203 项 Rust 测试通过，7 项显式探针按原设置忽略；23 项 Node 测试、Svelte、生产构建、Clippy 全目标零警告、Rust 格式及前端格式检查通过。
