# 0.1.2 默认深色外观与消息刷新

用户最终要求默认外观改为深色。Rust `Settings::default()` 与前端初始快照均改为 `dark`；语言默认仍为 `system`。已保存的主题和语言不被迁移覆盖，用户仍可选择浅色或跟随系统。

继承 0.1.1 的 380 × 800 面板、语言设置、原生浅色修正、双语 README 和透明圆角截图；[详细验证](settings-and-readme-0.1.1.md)。README 不将语言支持作为特性。

本机现有应用的外观已确认是深色，语言为用户选择的中文。本次升级保留这些设置。

## 消息手动刷新

此前点击刷新被本地指数退避阻止，但没有排队反馈。现在手动重试可重新尝试临时失败，服务端明确 Retry-After 和 HTTP 429 等待继续保留；旧版 429 记录按原退避保守处理。重复点击间隔至少 30 秒，同一组请求保持不重叠，两个资源的服务端等待分别保留。

刷新 IPC 返回实际等待时间，按钮提供请求中 / 重试状态及点击反馈。退避显示下次尝试的本地时间，增大按钮点击区域。403 是上游拒绝响应，手动重试不保证服务端立即恢复。
