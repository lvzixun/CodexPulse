# i18n 与 macOS 0.1.0 预览发布

本轮按用户要求添加中英文、更新 README / 设计 / 交接、发布 macOS 包，并清理仓库编译与调试缓存。正式签名与公证延期，八小时采样已取消。本文记录实际检查，不代表完整首版验收。

## 语言契约

- 使用系统**首选显示语言**，不使用地区设置或 shell `LANG`。macOS 为 `NSLocale.preferredLanguages().firstObject()`；Windows 为 `GetUserDefaultUILanguage()` 的主语言 ID。
- `zh`、`zh-CN`、`zh-Hant-TW` 等中文变体使用简体中文；英文和所有其他语言回退英文。首选法语、次选中文仍应显示英文。
- WebView 挂载前读取语言，避免先闪现另一种语言。面板可见时复用已有每分钟时钟检测，重新显示时检测；隐藏不添加语言轮询。原生托盘标签在变化时重建菜单。
- Svelte 文案使用响应式 translator；英语集中为 450 个消息条目，中文源字符串为消息 ID。插值参数逐项测试，数量复数使用英文 `Intl.PluralRules`。日期 / 紧凑数字跟随语言，USD 保留 `$` 与千分位。
- 姓名、用户名、模型 ID、来源标签、用户标题、第三方正文保留原始内容。已知产品错误在渲染时翻译，未知中文错误在英文界面显示英文失败提示，不改写存储中的原始错误。
- 自审修正托盘刷新可能在主线程立即执行时持有互斥锁的问题：分发前释放锁，失败时仅使匹配语言状态失效，以便下次重试。

入口：`apps/desktop/src/lib/{i18n,system-language}.ts`、`locales/en.json`、`src-tauri/src/language.rs`。bundle 声明 `en` / `zh-Hans`。
