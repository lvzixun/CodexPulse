# 0.1.23 模型运行速度

## 行为与口径

模型列表新增近 50 轮加权均速，限定在列表的最近 30 天范围。展开后在同一详情卡中显示连续曲线，可切换最近 50 轮、100 轮、30 天。横轴按测量时间的真实比例布局，显示设备本地时间，跨日附日期；不压缩空闲时间，不为无样本时段制造零速。曲线平滑连接观测值，悬停 / 聚焦点可查看实际样本，插值不作为额外测量。

均速为有效样本总输出 / 总运行耗时，排除轮次之间的会话空闲。日志只提供轮次起止计时，因此仍包含轮内推理、工具和等待，不声称是纯解码速度。历史仅纳入已完成且计时有效的轮次；当前只显示已连接来源中最近一个、60 秒内且仍与会话当前模型及输出样本相符的运行，不叠加并行任务的速率。

当前速度显示 Fast / 标准等模式，悬停 / 聚焦说明模型、时间、均速与计时边界。模式仅来自本轮日志；priority / default 分别规范为 fast / standard，缺失保持未知，轮内模式变更标为混合，不根据速度或模型推测。历史汇总含不同模式时显示混合。模式未知时不能证明服务端实际使用哪种通道。

30 天范围按 UTC 时间桶汇总，每桶按输出 / 耗时加权，显示为本地时间；最多约 120 个历史点，当前点另计。最近轮次范围每轮一个点，最多 50 / 100 点。相同测量时刻的绘图点加权合并，避免零宽曲段。

## 存储与采集

- schema 8 新增独立 `run_speeds` 表和模型 / 完成状态 / 时间索引，不修改已有 usage facts 或参考价。
- 样本 ID 由版本、逻辑会话、轮次、模型和起始时刻生成，不包含来源 ID；镜像或归档重读去重。已完成样本不被未完成旧样本覆盖。
- 实时采集与样本写入同事务推进检查点；解析器版本仍为 4，不触发全账本重放。
- 旧日志使用 `run-speed-v1:` 独立检查点，每批最多 64 行 / 1 MiB / 8 ms，后台每次迭代给历史队列约 8 ms。可重启续采，未完成时说明历史补采中。
- 历史补采丢弃 usage fact、会话元数据和解析问题输出，不改写账本、会话状态、健康状态或原有文件游标。来源停用 / 不可用时不读取，不唤醒已停止 WSL。
- 计时矛盾、无输出、缺失起始或轮次 ID、模型中途改变、父会话早于子会话创建的复制历史不会生成有效历史速度。
- 数据仅增加会话 ID、模型、起止时间、计数及模式；不保存正文，不读取新增凭据，不新增 HTTP 调度。
