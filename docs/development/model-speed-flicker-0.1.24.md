# 0.1.24 模型速度闪烁修复

模型页为了实时速度订阅快照更新，但原来每次更新都把列表置于加载状态，按钮禁用样式将整行透明度降到 0.55，查询完成后又恢复，造成周期闪烁。

现在按请求参数识别首次读取、范围 / 分页切换与后台更新。后台更新保留现有数据、按钮亮度和交互，成功时替换数值；失败保留最后成功列表与曲线并显示错误。后台完成不重复恢复页面滚动；速度曲线同样只在首次或范围切换时标记忙碌。请求序号仍拒绝过期结果，不改变本地采集或网络请求策略。

真实 Svelte + 官方 IPC mocks 回归覆盖中英文、320 / 380px；刻意挂起列表和曲线查询，连续三次推送快照，验证按钮未禁用、透明度稳定、行及 SVG 节点保留、曲线路径稳定、焦点保留，后台列表失败保留内容并可自动恢复。原有模式、范围、时间、主题、错误缓存、样本过期回归继续通过。Svelte 零错误 / 警告、Node 22 项和生产 UI 构建通过。Rust 实现未改变，双平台 CI 仍执行完整检查。

已发布 [0.1.24 双平台正式版](https://github.com/lvzixun/CodexPulse/releases/tag/v0.1.24)，构建源 `62f93a8`，CI `37795770836` 全部成功：Windows 188 项 Rust 测试、macOS 189 项，各 7 个联网探针按设计忽略；Node 22 项、Clippy 和 Svelte 检查通过。另跑 60 种外观组合与已有中英文面板回归通过。

macOS DMG 与更新归档核对版本、最低 macOS 12、arm64 / x86_64、严格 ad-hoc 签名和关键文件一致。两个平台更新包签名、版本绑定与篡改拒绝通过；正式发布前后全部 7 个服务端资产的大小 / SHA-256 与本地一致，最新正式版 API 和匿名公开更新清单均为 0.1.24。

本机 `/Users/zixun/Applications` 与 `/Applications` 两份 App 已安装 CI 正式包，关键文件与签名核验通过。原生设置确认 v0.1.24，模型页展开历史曲线与当前速度正常显示，完成设置返回后恢复原模型展开项。闪烁的延迟查询与节点 / 透明度稳定性由上述浏览器回归直接验证；Windows 本轮未做安装交互实测。
