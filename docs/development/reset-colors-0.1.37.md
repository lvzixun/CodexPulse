# 0.1.37 统一重置类型名称与颜色

重置历史图例、日期悬浮提示和选中日期详情使用与提醒卡片相同的名称：“硬重置”“重置卡”。名称共用 `resetTypeLabel`，同日两种事件显示为“硬重置 / 重置卡”。

总览和 Tibo 的提醒类型徽标按类型着色，与历史图例和日期格子一致：硬重置使用当前主题强调色，重置卡使用琥珀色，未知类型徽标使用灰色。
