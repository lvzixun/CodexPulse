# 0.1.36 重置提醒显示类型

总览和 Tibo 共用的重置提醒卡片在右上角显示重置类型：`banked` 显示“重置卡”，`regular` 显示“硬重置”，缺少或无法识别的类型显示“类型待确认”。计划时间待定、计划过期的状态行继续保留类型。消息列表的重置公告标签和系统通知正文同步使用这些名称。

类型直接来自已有 `reset_type` 字段，提醒与通知的发现、去重及执行确认规则沿用原有逻辑。
