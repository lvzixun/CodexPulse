# 0.1.41 官方价格同步与参考费用

用户反馈总览及所有模型长期显示“待计价”。原实现只内置三个 OpenAI 模型，且将 OpenAI 的服务档位、缓存写入数量及单次请求大小作为全部模型的共同硬性条件；DeepSeek 和自定义网关因此无法得到参考费用。文案没有区分缺少价格、缺少字段与不透明模型标识。

## 实现

新增固定官方来源的 OpenAI Markdown / DeepSeek HTML 价格解析与每日后台更新。安装包包含最新核查快照，缓存按供应商独立保存和回退；请求复用公开网络代理，不传账户认证。仅在完整校验后的价格变化时重算已有参考投影，失败不覆盖有效价格。详细来源及限制见 [参考价说明](../../resources/pricing/README.md)。

当前参考估算与历史严格计价分开：网关标识不否定已知模型的官方参考价，未知档位明确按标准档估算；未知上下文 / 缓存维度给出费用范围。DeepSeek 使用峰谷价格范围，不依赖 OpenAI 档位。已知缓存写入数量但未知其 30 分钟 / 12 小时时长时，也不会写入一个假精确的历史金额。

模型详情允许将 `mode-…` 等标识关联到支持的官方模型，保存后重算，可取消。原始模型名和事实保留。界面统一显示范围、未覆盖部分、具体缺失原因、假设及价格日期；诊断只增加价格同步失败 / 参考估算失败的布尔状态，不输出模型关联或用量。

Schema 9 只向可重建的参考投影增加上界、标记及原因，并更新覆盖索引；原始事实、断点及历史金额保留。单条损坏 JSON 标明异常后继续推进，数据库等计算错误单独提示。

## 验证范围

覆盖官网表格解析 / 变更拒绝、缺失计价维度的范围、DeepSeek 独立规则、30 分钟 / 12 小时写入、日期别名及手动关联、每日同价不重算、缓存失败与 Retry-After、迁移保留和坏记录隔离。程序已实际读取两家官方价格页并成功解析；16 组真实 Svelte + Tauri IPC 模拟回归覆盖双平台布局、中英文、深浅主题、320 / 380 宽度及关联保存 / 取消。

正式发布需通过双平台 CI、更新签名及公开资产 / 清单校验。未声称覆盖所有供应商、所有第三方网关别名，或完成反馈用户原机验收。
