# 0.1.27 Windows 重置状态卡片

Windows 总览重置信息使用共用基础样式，原来只有上下边线；macOS 的 `.menubar` 覆盖样式才提供卡片背景，因此两平台外观不一致。

基础重置状态改为与最近会话一致的主题背景、15px 圆角和 14px 内边距。移除两块之间的多余横线，用间距分组；macOS 保留已有背景、边框和 12px 圆角。最近重置和下一次状态仍按标签 / 数值两行排列，每行左右对齐。已有未来计划继续使用单层强调色倒计时卡片，避免双层背景。

仅修改界面布局和样式，不增加网络请求、计时器、依赖或采集工作。

- `scripts/verify-appearance.cjs`：60 组深浅 / 系统主题、五种强调色、双平台及中英文组合通过。检查重置卡背景与最近会话一致、圆角一致、Windows 内边距一致、无额外分隔线，并保留单行重置状态及清晰的选中 tab。
- `scripts/verify-panel.cjs`：中英文回归通过，包含未来重置计划在总览 / Tibo 的单层卡片、深浅主题、离线、倒计时到期、拖动与现有账户缓存行为。
