# 0.1.1 设置、布局与文档修正

## 行为

- 设置增加「跟随系统 / 中文 / English」，默认跟随系统。zh 及地区变体使用简体中文，未支持语言回退英文；日期和数量跟随界面语言，账户名字、会话标题和来源正文保留原文。
- 语言与外观独立即时保存，不提交其他来源或隐私草稿，也不清除已核验额度缓存。普通设置保存保留最新已应用语言和外观。
- 浅色问题原因为前端使用未保存外观草稿，原生背景仍使用旧主题；材质缓存也未区分主题。现在文字使用已应用主题，NSWindow 明确设置 Aqua / DarkAqua / 系统外观，材质缓存包含主题。
- 详情窗口由 macOS 400 × 680 调整为 380 × 800 逻辑像素；Windows 详情也采用相同尺寸。顶部、页边及分隔留白收紧。工作区不足时限制窗口尺寸，长列表保持滚动。macOS Retina 和小工作区定位回归通过。
- README.md 与 README.en.md 独立维护、相互切换，语言支持不列为特性。截图按单列展示各自语言，使用虚构账户和示例数据。SVG 使用真实前端截图和圆角裁切，外侧透明，不把桌面白底嵌入边角；前端截图不模拟 AppKit 材质。

- 380 × 800 中文 / 英文总览、模型和 Tibo 已通过前端预览检查，截图已更新；半年的重置历史在可用宽度内展示。
- 已安装 macOS 原生面板实测浅色 / 深色 / 跟随系统切换，浅色背景与深色文字同步；英文 / 中文 / 跟随系统即时切换通过。退出再启动确认英文、浅色持久化，日期和数量改用英文格式，中文会话标题保留原文。测试后恢复语言及外观跟随系统。
- 原生面板实际为 Retina 760 × 1600 像素，对应 380 × 800 逻辑像素。安装应用与构建产物四文件 SHA-256 完全一致。
