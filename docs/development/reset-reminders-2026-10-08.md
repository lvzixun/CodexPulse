# 总览与 Tibo 的下一次重置提醒

总览的“下一次已确认重置”改为带铃铛、主题色底纹及“即将重置”标记的提醒卡。突出剩余天 / 小时 / 分钟，下方显示按统计时区格式化的计划日期与时间。Tibo 在最近一次重置与统计指标之间显示相同卡片，复用同一组件和判定。

只有 Tibo 的已公布 scheduled 计划进入确认提醒，站点 forecast 继续保留在独立的“重置观察”中，不提升为确认计划。没有时间的计划显示“时间待定”；到达计划时间后自动改为“待确认执行”，无需网络刷新。可信的同类重置执行公告可清除对应缓存计划；备用卡发放与社区观察不能确认常规重置。没有新计划时，总览保留“尚未公布”，Tibo 不增加空卡。

提醒注明公开计划以执行公告为准，离线时明确标记缓存。仅为面板内视觉提醒，没有新增系统通知权限、网络请求或定时器；继续使用已有本地界面时钟。中英文及深浅主题沿用现有设置。

验证：Svelte 检查 0 错误 / 0 警告，18 项前端测试通过，生产前端构建成功。IPC 模拟回归验证两页显示同一倒计时和时区、320 / 380 DIP 下不截断、深浅主题、离线标记及计划到期后的状态切换，同时保留更新检查只在启动 / 手动发起的回归。另生成 macOS 样式的合成数据预览供用户查看；浏览器预览不等同于 macOS 原生材质或系统通知验证。

本次尚未打包、发布或替换本机应用，本机安装仍为 0.1.19。未生成 Rust target。
