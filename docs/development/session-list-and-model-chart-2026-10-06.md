# Sessions 列表、模型图表与通知取消验证

日期：2026-10-06。Windows x64，本次改动沿用已有 HTML 布局及主题。

## 行为

- Sessions 收起行只显示标题、状态、最近活动时间和箭头，点击该行展开详情，再次点击收起。模型与计价依据放入二级展开区，详情分类继续每页最多 50 条。
- 全量匹配历史按运行状态优先、活动时间倒序，每页 10 条。运行需要 active 状态、最近 5 分钟活动及已连接来源；其他未结束会话显示未知。分页游标固定判断时刻，避免自然时间推移改变分组；后台数据仍可继续更新。
- 模型行用主题色细横条显示 tokens 占比。分页查询同时返回全部模型的已知总量及缺失记录数，分母与分类共享范围 / 账本水位，新增 facts 不改变后续页比例。全部未知不画零值条，部分缺失有 `*` 和说明。
- 总览在额度后、当前 session 前显示最近 / 下一次已确认重置，删除重复 Tibo 入口和本地时间说明；消息页保留挑战和动态。
- 用户取消通知功能后移除原生通知、提醒设置、低额度 / 恢复事件、免打扰和通知历史，恢复原生依赖与安装配置。HTML 演示通知开关也移除。消息页与浮窗中的未读标记保留，不启动系统通知或额外恢复核验任务。
