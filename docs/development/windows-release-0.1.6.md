# Windows 对齐与双平台发布 0.1.6

日期：2026-10-07，Asia/Shanghai。仓库继续保持私有。

## 版本与范围

同步另一台机器的 macOS 0.1.3 实现及 `6455382` 的 0.1.5 重置观察。远端已存在 `v0.1.5` 标签，不重写标签；Windows 增量使用 0.1.6 同源构建双平台。0.1.4 / 0.1.5 标签均不能代表本轮最终安装包。

Windows 补齐当前用户登录启动、系统启动审批状态读取、Unicode 脱敏诊断复制与有界窗口生命周期记录。共享总览、模型图表、运行优先会话列表 / 展开详情、Tibo 半年历史 / 28 天挑战 / 重置观察、中英文及刷新设置。保留 184 × 36 桌面浮窗与简单托盘菜单。

账户自动刷新仅在 Windows 详情展开且可见时派发，小浮窗 / 托盘启动不进行首轮请求；收起后不派发后续账户子请求，已发出的请求可完成。展开沿用原到期时间、单飞与退避。Resets 与本地日志采集独立。小浮窗显示当前任务模型及本轮平均输出速度，模型切换不沿用旧速度；任务开始早于模型上下文时保留尚未产出 token 的计时，回归测试覆盖首轮速度及旧速度清除。

卸载器使用与锁定 Tauri CLI 2.12.1 对应的官方 NSIS 模板，只修改默认 Run 删除处为本安装命令准确匹配；原 hook 会被默认删除逻辑绕过，已移除。模板保留来源和 MIT 许可，升级 CLI 时须对照上游同步。

macOS 的本次 CI 验证已通过 Rust 143 项（6 项联网探针忽略）、Node 15 项测试及 Clippy、Universal 构建、严格 ad-hoc 签名验证及 arm64 / x86_64 架构校验。另一台机器的原生 UI 证据见 [0.1.5 记录](reset-watch-0.1.5.md)。本轮不声称 Windows 多屏拔插、真实注销登录、Intel Mac 实机或长期漂移已验收。

最终 0.1.6 本机包再次验证：10:07:25 启动为小浮窗，至 10:17:37 账户 last_attempt / last_success 仍停留在启动前 10:01:32，本地 facts 从卸载检查时的 12,822 增至 12,855（+33）。模型与速度持续显示，没有用本地模型 / 速度展示触发账户网络刷新。
