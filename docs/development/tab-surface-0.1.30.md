# 0.1.30 macOS Tab 底框

原导航条使用透明度较高的中性灰底色，与原生 Popover 磨砂背景接近。后方窗口较亮时，整组 Tab 的底框几乎不可辨认。

macOS 导航条改用深浅主题各自的稳定中性底色与细描边，跟随系统主题时使用对应颜色。保留窗口原生磨砂、布局、选中样式和 Tab 操作；Windows 样式不变。

## 验证

- 既有 60 组主题 / 强调色 / 平台 / 中英文外观检查通过。
- 16 组主题 / 亮暗背景 / 320、380px 检查通过：未选中 Tab 文字对比度至少 4.5，按钮位于导航框内，正文与导航框分离，切换正常。
- Svelte 零错误 / 警告、生产 UI 和本机 App 构建、格式及 diff 检查通过。
- 本机 `/Applications/CodexPulse.app` 已安装 0.1.29 修复候选并原生重启，确认深色磨砂下完整底框可见，模型 / 总览切换正常。浅色 / 跟随系统由浏览器回归覆盖，未写成原生验收。

## 发布

版本统一为 0.1.30，待 Windows x64 与 macOS Universal CI、签名和资产核验后发布。
