# 0.1.3 账户自动刷新与子代理过滤

## 后台调度

只有 OpenAI 账户自动调度新增可见性条件。自动模式启动首轮可在窗口未创建时执行；实际派发成功后消耗首轮许可，失败、配置 / 身份变更、窗口销毁和重建均不重新授予许可。未成功入队不消耗许可。

后台每轮读取当前原生窗口可见性，窗口不存在按隐藏处理。隐藏不取消在途请求、不修改计时器或退避；到期后重开只经原单飞调度派发一次，未到期复用缓存。持续显示仍按原设置间隔执行。显式手动刷新继续使用原队列和等待逻辑；手动模式不会在启动、重开或定时器中自动发请求。

Resets 沿用 `Schedule::due` 和原独立退避 / 缓存期限；本地采集、身份只读校验、tokens、轮次速度及 WebView 隐藏释放路径不变。既有每来源服务端等待及失败退避继续由账户筛选保留，开关窗口不重置这些状态。

## 子代理

按用户确认，只排除会话列表与会话数量，保留 tokens / 费用和原始账本。明确的 `source.subagent` 标记归为 subagent；普通 fork、缺标题及未知来源仍可见。过滤在 Rust 查询的分页 LIMIT 之前执行，涵盖总览最近会话、Sessions 及模型下钻；总览和模型的独立会话数同口径，详情入口也不返回子代理。

旧 checkpoint 仅补读最多 256 KiB 的首条元数据，事务内更新来源分类与 checkpoint 标记，不回退读取偏移、不重放累计计数、不改变活动时间或速度。完成后未变化文件再次保持零正文读取。模型列表在会话数量改变后刷新，其他统计投影不删减子代理用量。
