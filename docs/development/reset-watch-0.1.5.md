# 0.1.5 重置观察

## 问题与行为

站点公开状态接口已经提供 `active_watch`，原 UI 将其合并进历史动态而未在总览展示，因此容易遗漏。现在 Tibo 顶部和总览重置区域共用一份观察，显示“有迹象”、小时 / 分钟倒计时及本地预计截止时间。Tibo 同时展示最近线索正文、原文与翻译入口，不引入第二层 tabs。

观察是站点预测，尚未确认，不代表当前账户额度恢复。观察不能替代“下一次已确认重置”。使用已有界面时钟；到期或出现更晚的已执行重置即隐藏，缺失 / 无效 / 未来观测时间不推算显示。没有新增轮询、修改账户刷新时机或改变 Resets 的独立刷新调度。

## 数据与失败处理

从状态缓存投影独立 `active_watch`，不受最近 100 条历史消息上限影响。状态数据先验证，历史请求失败仍保留刚获得的状态及观察；历史旧缓存、失败状态和退避继续保留，未将部分成功伪装成整组同步成功。`no-store` 数据不落盘。

翻译读取站点已发布的 `.watch-tweet` 正文，排除引用上下文、脚本和样式，不执行来源脚本；独立观察也能按 ID / 原帖 ID 查询译文。沿用响应体大小上限、ETag、HTTPS 校验和服务端等待。
