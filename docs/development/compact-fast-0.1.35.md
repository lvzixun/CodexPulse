# 0.1.35 隐藏关闭的 Fast 状态

macOS 菜单栏和 Windows 小浮窗在 Fast 明确关闭时隐藏 `Fast off`，例如菜单栏显示 `忙 · 6-astra max · —t/s`。小浮窗不再渲染对应标签，菜单栏不保留额外空格。开启时仍显示 `Fast`，未知状态显示 `Fast ?`，同模型并行会话状态不一致时显示 `Fast±`。

## 验证

- 本地 203 项 Rust 测试通过，7 项显式联网 / 实机探针按原设置忽略；23 项 Node 测试、Svelte 检查、前端生产构建、Clippy 全目标零警告、Rust 格式和修改文件的前端格式检查通过。
- 中英文 Svelte / IPC 回归通过，覆盖四种关闭服务层级、开启、未知状态及 184px 浮窗布局；关闭时标签不存在，模型、推理级别、速度和消息流程正常。
- 菜单栏回归确认关闭时完整标题没有 Fast 标签或多余空格，开启、未知及并行混合状态正常。
